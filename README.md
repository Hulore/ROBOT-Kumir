# КУМИР · Робот — веб-практикум

Веб-среда исполнителя «Робот», которая работает прямо в браузере. Установка и сервер не требуются.

## Возможности

- движение по клетчатому полю и закрашивание клеток;
- редактирование размера поля, положения Робота, целей и стен;
- проверка столкновений со стенами и границами;
- команды `вверх`, `вниз`, `влево`, `вправо`, `закрасить`;
- циклы `нц N раз … кц` и `нц пока условие … кц`;
- условия `если … то … иначе … все`;
- автоматический и пошаговый запуск;
- свободный режим без встроенной учебной части;
- локальное сохранение кода, поля и темы;
- адаптивный интерфейс для компьютеров и телефонов.

> Это браузерная реализация исполнителя «Робот», а не полный перенос среды КУМИР. Синтаксис пока ограничен командами Робота.

## Локальный запуск

Откройте `index.html` в браузере. Также можно запустить любой статический сервер, например:

```bash
npx serve .
```

## Публикация на GitHub Pages

Workflow в `.github/workflows/pages.yml` публикует сайт после каждого push в ветку `main`.

1. Откройте репозиторий на GitHub.
2. Перейдите в **Settings → Pages**.
3. В разделе **Build and deployment → Source** выберите **GitHub Actions**.
4. Сделайте push в `main` или вручную запустите workflow **Deploy to GitHub Pages**.

После публикации сайт будет доступен по адресу:

`https://hulore.github.io/ROBOT-Kumir/`

## Структура

- `index.html` — разметка приложения;
- `styles.css` — оформление и адаптивность;
- `app.js` — задания, интерпретатор и симуляция Робота.
